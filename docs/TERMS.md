# Termos de Uso

Estes termos descrevem as condições gerais de uso do Meg Pocket.

O Meg Pocket é uma ferramenta open source para apoio a mesas e campanhas de RPG no universo Magos & Grimórios. O projeto permite criar contas, fichas de personagens, anotações e gerenciar informações relacionadas ao jogo.

## Uso do Projeto

Você pode usar o código-fonte, criar forks e adaptar a aplicação conforme as licenças do projeto.

O código é distribuído sob a licença MIT.

Os conteúdos narrativos, estruturais e mecânicos de RPG incluídos no repositório são licenciados sob CC BY-NC 4.0, salvo indicação em contrário. Isso significa que podem ser usados e adaptados para fins não comerciais, com atribuição ao projeto original.

## Dados de Seed

O projeto inclui seeds com dados estruturais e fictícios para funcionamento do sistema de RPG, como classes, raças, magias, itens, campanhas, personagens de exemplo e usuários locais de teste.

Esses dados são fornecidos para desenvolvimento, demonstração e uso em mesas ou campanhas próprias. Eles não representam pessoas reais.

Os comandos de seed podem apagar dados existentes nas tabelas alvo. Use seeds apenas em ambientes locais ou de desenvolvimento.

## Responsabilidade de Quem Hospeda

Ao executar este projeto localmente, em um fork ou em uma instância própria, você é responsável pelos dados inseridos nessa instalação.

Se você hospedar uma instância para outras pessoas, também é responsável por informar como os dados pessoais serão tratados, criar uma política de privacidade adequada e cumprir a legislação aplicável.

## Conteúdo Inserido pelo Usuário

O usuário é responsável pelo conteúdo que inserir no sistema, incluindo nomes, descrições, anotações, URLs de imagem, fichas e campanhas.

Não insira dados pessoais sensíveis ou informações reais de terceiros em campos livres.

Não use o sistema para armazenar, divulgar ou compartilhar conteúdo ilegal, abusivo, ofensivo ou que viole direitos de terceiros.

## Uso Não Comercial do Conteúdo de RPG

O conteúdo narrativo e estrutural do RPG Magos & Grimórios incluído neste repositório não pode ser usado comercialmente sem autorização prévia.

Você pode criar campanhas, mesas, forks e adaptações não comerciais com base nesse conteúdo, respeitando a atribuição ao projeto original.

Você pode modificar o banco de dados, trocar seeds e criar classes, raças, magias, itens, campanhas e regras próprias para sua mesa. Conteúdos totalmente novos criados por você pertencem a você; adaptações diretas do material original continuam sujeitas à licença de conteúdo do projeto.

O nome Magos & Grimórios, a identidade do sistema e eventuais marcas ou logos do projeto não concedem afiliação, endosso ou autorização comercial automática.
